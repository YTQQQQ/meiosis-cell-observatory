# 减数分裂观察室

这是一套可独立托管的静态教学动画。打开在线版，在「拆开观察」里先辨认同源染色体和姐妹染色单体，再点「开始学习」。首页预览的是减Ⅰ中期的已复制细胞，正式学习从复制前开始。

## 在 iPad 上使用

- 单指拖动三维画面旋转，双指捏合缩放，双指同向移动可平移。用画面右侧的全屏键扩大观察区域，再点一次退出。「恢复标准视角」可将模型重新居中。轻点模型中的染色体开启追踪。「选择细胞与追踪对象」也可按名称选择。短染色体保留来源色和追踪身份。
- 暂停后可来回拖动时间轴。分步模式每完成一个事件停下，点「继续」进入下一阶段；连续模式可看完全过程。播放器提供 0.25、0.5、1、2、4 倍速。
- 「时期目录」可以直达任意阶段。「观察设置」可更换标注、基因标记、膜透明度和剖面。「教材图」使用标准方向画出同一时刻的几何结构。
- 在减Ⅱ阶段选择一个细胞放大，画面左下角保留所有细胞的预览。点击数据卡上的小曲线可直接定位；展开数量曲线可切换一个细胞、一极、画面合计。
- 在「交叉互换」示例中，两个基因均在长染色体上。「自由组合的另外一种情况」会定位至减Ⅰ中期，进入两基因分处长短染色体的独立示例。成对转动是两次可能取向间的教学过渡。转动结束后点「查看产物」核对本次组合，再按同一入口可切回另一种情况。拖动时间轴可中断演示，保留最近完成的取向。
- 上方「对照学习」与「判图练习」可独立使用。点击「朗读」启用系统语音，中文发音取决于浏览器及系统语音包。

## 运行和部署

公开课堂地址为 https://ytqqqq.github.io/meiosis-cell-observatory/ 。在 GitHub 仓库的 Settings → Pages 中将 Source 设为 GitHub Actions。推送到 main 后，已有工作流发布 dist 目录。课堂运行时从同一网站加载脚本和样式。

源码解压后直接用桌面浏览器打开 dist/index.html，或在解压目录中执行：

    python3 -m http.server 8000 --directory dist

Windows 安装 Python 后也可使用：

    py -m http.server 8000 --directory dist

在同一台电脑上打开 http://localhost:8000/ 。局域网测试时，让 iPad 和电脑连接同一 Wi-Fi，再用 iPad Safari 打开电脑的局域网 IP 与端口 8000。防火墙须允许局域网访问。任何支持静态文件的 HTTPS 主机都可部署，直接上传 dist 目录的内容，保留文件名。无需安装前端依赖、运行编译任务或设置密钥。源码包为了避免递归压缩，省略了自身；需要保留页面底部的源码下载功能时，将原 ZIP 也放到部署目录中，命名为 meiosis-source.zip。

## 文件

- dist/index.html、style.css：自适应界面、播放器与对话框。
- dist/model.js：染色体谱系、基因、时间轴、胞质分裂、受精、数量状态。
- dist/optics.js：WebGL 立体材质、连续分裂沟、投影与 Canvas 降级。
- dist/diagram.js：从同一场景绘制教材图、练习图和缩略图。
- dist/lessons.js：两个上海教材版本的对应说明、分步讲解、术语与原始资料链接。
- dist/lens.js：结构拆解、复制叉和非姐妹染色单体交换片段的独立放大镜头。
- dist/app.js：控件、曲线、追踪、对照和判图练习。
- tests/：可重复运行的模型和浏览器验收。TEST-RESULTS.md 记录本次实际检查。

## 教学模型

虚拟二倍体动物 2n＝4，以两对常染色体为例。模型允许选择单次互换或无标记互换，并观察一次具体的取向。统计使用高中题常见的染色单体口径；S 期用范围或DNA含量表达复制进程。减Ⅱ后期每一极为一组，全细胞短时可数出两组。曲线默认按所选谱系的一个细胞计算。受精段单独取一个配子及另一亲本的配子，画面总计的统计对象随之改变。

卵细胞路线选用第一极体继续分裂的教材模型。学习手册与深入解释说明物种差异，以及人类卵子发生中的停滞。材质、颜色、缩放和播放时长服务于观察。
